# Navigational-shelter identity

The mark is an open vessel moving with the current. It gives the overwhelming
feed a human-scale metaphor: a person no longer has to swim through the
network alone, but can still move through it and participate.

## Rules

- Preserve the open upper shelter, the broad first current, and the quieter
  second current beneath it.
- Keep the mark open and in motion. It is a vessel, not a wall or shield.
- Do not add people, sails, flags, anchors, compass imagery, or literal nautical
  decoration.
- Avoid nodes, graphs, circuitry, brains, robots, hourglasses, and clocks.
- Use the same optically reduced silhouette for navigation and app icons.
- Keep the palette to warm paper (`#FDFBF7`) and forest green (`#0F4A38`)
  when the mark is shown alone.

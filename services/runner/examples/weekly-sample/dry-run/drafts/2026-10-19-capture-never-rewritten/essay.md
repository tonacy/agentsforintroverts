# The one file my agent is not allowed to rewrite

*Quiet Desk starts each day from words I wrote, marks them as mine, and won't run without them.*

Every day in Quiet Desk starts with a capture. It is a short file I write myself. At the top it carries one line of metadata: `author: human`.

The runner reads that file before it does anything else. It quotes it. It hashes it. If the capture is missing, the runner refuses to run. And at no point does it edit the file.

That is the whole mechanism. Four rules, none of them clever. But they decide what the rest of the day is built on.

## What the runner does with it

Here is each rule on its own, because each one closes a different gap.

**It is marked.** `author: human` sits in the file itself, not in a setting somewhere else. Anyone opening the capture, person or program, can see who wrote it.

**It is quoted.** When the runner uses the capture, it quotes it. My words show up as my words, not as a summary of what the agent thinks I meant.

**It is hashed.** A hash is a fingerprint of the exact text. Change one word and the fingerprint changes. The capture isn't only there to be read. It is recorded as it was.

**It is required.** No capture, no run. The runner has no fallback where it invents a starting point for me and carries on.

The fifth fact is the one the other four protect: the runner never edits the capture. It doesn't fix the typos, smooth the grammar or tidy the half sentences.

## The same line runs through this newsletter

This piece was made the same way. This week I added a Monday draft command to the runner. My agent reads the backlog of stories I've already agreed are public, picks one, and drafts the essay and posts. I review every word and publish by hand.

The boundaries are written into the tool, not left to my mood on a given Monday. One commit this week stops the draft outright if it names a private term. Another keeps the replies I paste in after each piece, so the next Monday can read them.

The draft also leaves gaps. Wherever a piece needs my reason, my frustration or what I believe now, the agent is told not to supply it. It leaves a marker and asks me a question instead. The sections above that say YOU ADD are where I filled those in.

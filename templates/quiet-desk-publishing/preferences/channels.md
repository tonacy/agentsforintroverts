# Channel preferences

Review these before preparing a channel adaptation.

## Website / Field Notes

- Role: canonical source of record
- Shape: full note with sources, uncertainty, invitation, and agent ledger
- Default cadence: Thursday
- Links: allowed

## LinkedIn

- Role: reflective builder and founder narrative
- Voice: personal, plain, specific
- Default: one self-contained post; link only when it adds value
- Avoid: growth theater, generic lessons, invented certainty

## X

- Role: enter fast-moving discourse and invite counterexamples
- Voice: compressed without becoming absolute
- Default: one post or a short thread; native replies before link distribution
- Avoid: engagement bait, repeated link drops, artificial urgency

## Direct messages

- Never agent-sent.
- Tony sends the first message only after reciprocal public interest or an explicit opt-in route.
- Any ask or commitment is a separate exact proposal.
